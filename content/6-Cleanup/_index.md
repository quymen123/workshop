{{% notice info %}}
After the project has been deployed and is running smoothly, it is crucial to clean up and manage the resources used during the development process. This not only helps you avoid unnecessary costs but also maintains an efficient working environment. Below are the steps to optimize and clean up the AWS resources created during the project
{{% /notice %}}

#### 1. Delete AWS EC2 Instances
Deleting AWS EC2 instances is essential for cost management, as it reduces unnecessary charges for unused resources. It also enhances security by minimizing the attack surface, optimizes resource allocation, and improves clarity and organization within your environment. Additionally, regularly removing outdated instances helps ensure compliance with organizational policies, making it a best practice for effective resource management.

#### 2. Verify Cleanup
After deleting resources, it's important to check that all associated costs have been eliminated as a best practice. You can use AWS Cost Explorer to monitor and confirm that no charges are being incurred from any remaining resources.

{{% notice note %}}
By following these steps, you will ensure that your AWS environment is properly cleaned up, helping to prevent unnecessary costs and maintain a neat, efficient cloud infrastructure.
